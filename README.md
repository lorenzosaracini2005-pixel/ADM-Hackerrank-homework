## Repository Overview

This repository contains the completed solutions and submission printouts for **Hackerrank homework** of the Algorithmic Methods of Data Mining course.

### Structure of the Repository

- **`scripts.py`** (or Jupyter Notebook): Contains the Python implementations for the assigned HackerRank challenges, organized by topic and problem sections.
  - **Problem 1:** Core Python exercises covering language basics, data types, strings, sets, collections, datetime, exceptions, built-ins, functional programming, regex and parsing, XML, closures & decorators, and NumPy.
  - **Problem 2:** Algorithmic problem-solving challenges (including *Birthday Cake Candles*, *Number Line Jumps*, *Viral Advertising*, *Recursive Digit Sum*, and *Insertion Sort* variants).
- **`printouts/`**: Directory containing the submission screenshots that certify the successful completion and `Accepted` status on HackerRank.
